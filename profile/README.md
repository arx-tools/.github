Tools for **Arx Fatalis** (2002), Arkane Studios' first game.

- **[Arx Fatalis Browser Editor](https://github.com/arx-tools/arx-fatalis-browser-editor)**: open, edit and export levels in the browser, no install.
- **[arx-convert](https://github.com/arx-tools/arx-convert)**: the game's binary formats (DLF, LLF, FTS, FTL and friends) to JSON and back.
- **[node-pkware](https://github.com/arx-tools/node-pkware)**: the StormLib-compatible compression library behind them.
- **[arx-tools.github.io](https://arx-tools.github.io)**: the maps, the mods and the schemas in one place.

The maps and mods are not here: they live under [Lali's account](https://github.com/meszaros-lajos-gyorgy), because they are not tools.

Everything here is free, and stays free.
